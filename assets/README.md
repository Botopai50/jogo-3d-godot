# assets/

Pasta destinada aos assets importados no projeto.

- `grid/` — pacote de assets modulares **Grid**, que será baixado do release do repositório na
  **etapa 2**. A pasta está vazia de propósito: nenhum asset genérico substituto foi adicionado.

Os arquivos `.import` gerados pelo Godot ao importar os assets ficam em `.godot/` e não são
versionados.
